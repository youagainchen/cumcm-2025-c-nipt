## 产物文件

### `data/processed/male_min.csv`（给甲乙的 T3 快速版，10 列）
`mother_id, age, height, weight, bmi, week, y_conc, draw_idx, visit_idx, n_visits`
- 1082 条 / 267 位孕妇；`week` 已数值化。
- `visit_idx`=该孕妇第几次检测（按表中出现顺序），`n_visits`=总次数。
- ⚠️ **不是 1082 个独立样本**：同一孕妇多次测量高度相关，模型必须用混合效应处理（分工文档评分表：OLS 当独立样本直接 0 分）。

### `data/processed/male_clean.csv`（47 列 = 31 原始 + 派生 + QC + 问题二标记）
- `is_qualified`：本行 `y_conc ≥ 0.04`。
- `reached / first_pass_week / first_pass_visit / t_left / t_right / censored`：**问题二预置**——每位孕妇「Y 首次达标」区间，删失含义：
  - `none`：达标落在 `(t_left, t_right]`（两次检测之间首次达标）；
  - `left`：首测即达标，真实达标 ≤ `t_right`（下界取 0）；
  - `right`：全程未达标，**右删失**，真实达标 > 最后一次检测孕周。
- `flag_gc / flag_map_ratio / flag_dup_ratio / flag_filt_ratio / flag_any`：QC flag，只标记不删行。

### `data/processed/female_clean.csv`（44 列 = 31 原始 + 派生 + QC + 标签）
- `label`（AB 非空=1，异常 67/605）、`label_T13 / label_T18 / label_T21`。
- ⚠️ **标签只能用 AB 列**；AE 列全「是」，当标签模型必失效（问题四注意）。

### `docs/data_report.md`
自动生成：基本画像、缺失表、BMI 核对、QC 体检、问题二删失统计、女胎标签统计、孕周解析检查。论文引用其中的数字即可。

## 关键数据事实（写论文可直接引用）

| 项 | 男胎 | 女胎 |
|---|---|---|
| 记录数 / 唯一孕妇 | 1082 / **267** | 605 / **147** |
| 每人检测次数 | 4 次者 210 人（最多 8 次） | 4 次者 99 人（最多 9 次） |
| 孕周 | 11–29 | 11–28.4 |
| BMI | 20.70–46.88 | 25.59–45.72 |
| Y 浓度 | min 0.010 / 中位 0.075 / max 0.234 | — |
| 达标情况 | 260/267 曾达标 | — |

- **BMI 核对**：用身高体重重算与原列比对，男胎 400 条偏差 ≤0.0022（原始体重多为非整数值，K 由更精确原值算出），女胎完全一致。**建模用原 `bmi` 列即可。**
- **QC 体检**：男胎 451 条、女胎 220 条 GC 略低于 0.40（多为 0.39–0.40，边际偏低，见 data_report §四）。只打 flag 不删行，作为后续敏感性分析素材。
- **男胎 AB 列说明**：男胎表 AB 列有 126 行非空（82 位孕妇，如 T18×57、T13T18×25…）——这是常染色体（13/18/21）非整倍体筛查信号，男胎同样可有唐氏/爱德华氏/帕陶氏，**不是数据串表**。与对应 Z 值自洽（如含 T21 的行 z21 中位 2.32），但与出生结局 AE 几乎不重叠。问题 1–3 建模正常使用这些行即可；如需可在敏感性分析中分层查看。

## 数据纪律（全组必读）

1. **绝不要把 1082/605 条记录当独立样本**。同一孕妇重复观测 → 混合效应 / GEE / 按孕妇聚合，任选其一，但必须正视（分工文档评分项）。
2. **丙只打标、不删行**。删哪些、删多少留给敏感性分析。
3. **女胎标签只用 AB 列**；AE 列全为「是」，不可用。
4. 中文列名只在 `src/clean.py` 中出现一次，全组此后只碰英文短名。
5. 训练/验证集必须按孕妇分组切分，防同一孕妇的数据泄漏（仓库 README 协作约定）。
