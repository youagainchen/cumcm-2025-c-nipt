# 数据字典与清洗说明（阶段一，丙维护）

> 依据题面附录 1、[docs/C题_第一阶段分工.md](C题_第一阶段分工.md) 与评阅要点。
> 清洗产物全部可复现：在仓库根目录执行 `python src/clean.py`，
> 即从 `data/raw/附件.xlsx` 重新生成 `data/processed/` 与本文档同目录的 `data_report.md`。
> ⚠️ `.gitignore` 忽略了 `data/processed/*`：清洗产物不入库、由脚本复现，符合仓库约定。

**对照评阅要点的立场（丙按此设计管道）**
- 附件数据除少量空缺/录入不一致外**无需删行、插补、类别平衡**等常规预处理——本管道只加派生列与标记，绝不删/补/平衡。
- 数据来自实际、**测量/测算误差不可忽略**，纯 ML/大数据那套不适用 → 清洗保留全部原始统计量，并按
  `(孕妇, draw_idx)` 把「一次采血多次测序」聚合成**事件级**文件，供估计技术误差与问题一重复测量分层。
- 识别到的空缺/不一致（报告第九节）只记录、不处置。

## 产物文件

### `data/processed/male_min.csv`（给甲乙的 T3 快速版）
`mother_id, age, height, weight, bmi, week, y_conc, draw_idx, visit_idx, n_visits` + `rep_in_draw / n_reps_in_draw / is_tech_repeat`
- 1082 行 / 267 位孕妇；`week` 已数值化。
- ✅ **语义（v3 已修）**：`visit_idx` = 该孕妇**第几次抽血**（按检测日期时序），`n_visits` = **抽血次数**；
  同一抽血多次测序的多行共享同一 `visit_idx`，由 `rep_in_draw`（组内第几行）区分。
- ⚠️ **不是 1082 个独立样本**：同一孕妇多次抽血高度相关，且同次抽血含技术重复。模型请优先用
  `male_clean_event.csv`（每 (孕妇,抽血) 一行），或对行级做嵌套分层（孕妇/抽血/测序）；OLS 当独立样本直接 0 分。

### `data/processed/male_clean.csv`（行级，31 原始 + 派生/标记列）
- `is_qualified`：本行 `y_conc ≥ 0.04`（**行级事实**，仅作参考）。
- `reached / first_pass_week / first_pass_visit / t_left / t_right / censored`：**事件级(默认均值口径)**回填到行，
  同一孕妇同抽血各行列相同。删失含义：`none`=首达落在 (t_left,t_right]；`left`=首抽即达（真实≤t_right，下界0）；
  `right`=全程未达，右删失。**问题二的正式输入请用事件文件的同名字段（含 *_any 对照）。**
- `flag_chrono / flag_gc / flag_map_ratio / flag_dup_ratio / flag_filt_ratio / flag_any`：QC/时序 flag，只标记不删行。

### `data/processed/female_clean.csv`（行级，31 原始 + 派生/标记列）
- `label`（AB 非空=1，异常 67/605 行级 / 66/554 事件级）、`label_T13 / label_T18 / label_T21`。
- ⚠️ **标签只能用 AB 列**；AE 列全「是」，当标签模型必失效（问题四注意）。标签不平衡是天然事实，**不要过采样/平衡**（评阅要点）。

### 事件级文件 `male_clean_event.csv` / `female_clean_event.csv`
> 按 (孕妇, `draw_idx`) 一次抽血聚合成一行——**问题一/问题二建模的推荐口径**。
- 男胎 1021 事件 / 女胎 554 事件（行级 1082/605 → 事件级后不再把技术重复当独立随访）。
- 每行带 `visit_idx`（第几次抽血）、`n_reps`（该次测了几次）、`is_tech_repeat`、`flag_chrono`（孕周回退异常）。
- 男胎关键字段：`y_conc_mean / y_conc_sd / min / max`；达标两口径 `qual_any`（任一重复≥4%）与
  `qual_mean`（组内均值≥4%）。
- **问题二预置（事件级，时间轴=孕周）**：`reached / first_pass_week / first_pass_visit / t_left / t_right / censored`
  默认=**均值口径(qual_mean)**；同名 `*_any` 列=任一重复口径做敏感性对照。默认用均值口径
  （any 口径对同一次抽血取最大、系统性更早，见报告 §五 A029/A066 差 2–3 周）。
- 女胎事件字段：`label / label_T13 / label_T18 / label_T21`（组内任一异常）、`aneuploidy_raw`（合并）。
- `y_conc_sd` 仅在 `n_reps≥2` 时有值：事件内离散度 = 测量/技术误差量级（男胎中位约 0.0045，见报告 §八）。

### `docs/data_report.md`
自动生成：数据可用性声明、基本画像、缺失表、BMI 核对、QC 体检、**事件级问题二删失（均值口径默认 + any 对照）**、
女胎标签、孕周解析、技术重复量化（§八）、识别到的空缺/时序异常（§九）。论文引用其中的数字即可。

## 关键数据事实（写论文可直接引用）

| 项 | 男胎 | 女胎 |
|---|---|---|
| 行 / 抽血事件 / 孕妇 | 1082 / **1021** / **267** | 605 / **554** / **147** |
| 每人抽血次数 | 4 次者 237 人（最多 5 次抽血） | 4 次者 124 人（最多 5 次） |
| 孕周 | 11–29 | 11–28.4 |
| BMI | 20.70–46.88 | 25.59–45.72 |
| Y 浓度 | min 0.010 / 中位 0.075 / max 0.234 | — |
| 达标情况 | 260/267 曾达标（事件级均值口径） | — |

- **BMI 核对**：用身高体重重算与原列比对，男胎 400 条偏差 ≤0.0022（原始体重多为非整数值，K 由更精确原值算出），女胎完全一致。**建模用原 `bmi` 列即可。**
- **QC 体检（v3）**：GC 名义区间 40%~60% 之外男胎 451/女胎 220 条——但本数据 GC 集中在 0.386–0.421，
  固定区间不适配，故 `flag_gc` 改用**稳健离群**（男胎 26、女胎 25 条），名义区间仅作参考行单列（报告 §四）。
- **男胎 AB 列说明**：男胎表 AB 列有 126 行非空（82 位孕妇，如 T18×57、T13T18×25…）——这是常染色体（13/18/21）非整倍体筛查信号，男胎同样可有唐氏/爱德华氏/帕陶氏，**不是数据串表**。与对应 Z 值自洽（如含 T21 的行 z21 中位 2.32），但与出生结局 AE 几乎不重叠。问题 1–3 建模正常使用这些行即可；如需可在敏感性分析中分层查看。

- **技术重复（一次采血多次测序）**：男胎 40 事件/101 行、女胎 32 事件/83 行；男胎事件内 Y 浓度 SD 中位 ≈0.0045（量化测量误差，报告 §八）。**行级建模前请优先用事件级文件，或把 (孕妇,抽血) 作嵌套层。**
- **空缺/录入不一致**（报告 §九，仅记录不处置）：`lmp` 男缺 12/女缺 8；`gravidity` 男缺 300/女缺 165；少数孕妇 `height/age` 跨行不一致。

## 数据纪律（全组必读）

1. **绝不要把 1082/605 条记录当独立样本**。同一孕妇重复观测 → 混合效应 / GEE / 按孕妇聚合，任选其一，但必须正视（分工文档评分项）。
2. **丙只打标、不删行**。删哪些、删多少留给敏感性分析。
3. **女胎标签只用 AB 列**；AE 列全为「是」，不可用。
4. 中文列名只在 `src/clean.py` 中出现一次，全组此后只碰英文短名。
5. 训练/验证集必须按孕妇分组切分，防同一孕妇的数据泄漏（仓库 README 协作约定）。
