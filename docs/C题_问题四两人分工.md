# C题问题四两人分工：女胎异常判定（不含论文写作）

> **阶段目标**：以女胎 AB 列为唯一判定结果，建立可解释、可复现的异常判定方法，并用按孕妇分组的样本外验证评估性能。
>
> **分工原则**：一号负责“标签、特征与判定模型”，二号负责“验证、阈值与稳健性”。两条线从开局即可并行，只有一次短接口交接；本分工不包含论文正文写作。

## 0. 开局共同对齐（约30分钟）

### 0.1 固定数据与标签口径

- 正式建模单位使用 `data/processed/female_clean_event.csv`：554个抽血事件、147位孕妇，避免把同一次抽血的技术重复当成独立样本。
- 主任务标签为 `label`，即 AB 列非空记为1；当前为66/554个异常事件。
- 辅助任务分别使用 `label_T13`、`label_T18`、`label_T21`，当前事件级阳性数分别为22、45、13，允许同一事件多标签并存。
- **禁止使用 AE 列 `fetal_health` 作为标签**；该列在女胎数据中全部为“是”。
- 同一孕妇的多次检测标签可能变化：147位孕妇中44位至少一次异常，43位在不同检测中标签不一致。因此正式任务定义为“根据本次检测指标判定本次AB结果”，不能把任一次阳性强行回填为该孕妇全部检测均阳性。

### 0.2 固定防泄漏与评价规则

1. 训练集、验证集必须按 `mother_id` 分组，同一孕妇不得跨集合。
2. 标准化、缺失处理、特征筛选、模型选择和阈值选择都只能在训练折内完成。
3. 不做SMOTE、随机过采样或人为平衡；类别权重可作为候选模型，但必须与未加权模型对照并检查概率校准。
4. 主指标采用PR-AUC、灵敏度、特异度、F1和混淆矩阵；ROC-AUC与Brier分数作为补充，不能只报准确率或ROC-AUC。
5. 最终阈值由样本外预测确定，优先控制漏诊；建议预先规定“灵敏度不低于90%时特异度最高”，若数据无法达到则报告实际可达边界，不事后修改规则。

### 0.3 特征白名单

候选特征只取检测当时已知信息：

- 核心Z值：`z13`、`z18`、`z21`、`zx`；
- 浓度与GC：`x_conc`、`gc`、`gc13`、`gc18`、`gc21`；
- 测序质量：`reads_raw`、`uniq_reads`、`map_ratio`、`dup_ratio`、`filt_ratio`；
- 个体与时点：`bmi`、`week`、`age`，必要时加入校准后的身高和体重做敏感性分析。

不得作为特征：`aneuploidy_raw`、`label*`、`fetal_health`、样本编号、孕妇编号，以及任何由AB标签直接派生的字段。

## 一、一号：标签诊断、特征工程与可解释模型主线

### 任务清单

| # | 任务 | 依赖 | 交付物 |
|---|---|---|---|
| 1 | 数据审计：核对事件级聚合、标签组合、异常比例、缺失、QC标记、同一孕妇标签变化和特征共线性 | 无 | `outputs/q4_data_audit.csv`、控制台摘要 |
| 2 | 建立临床规则基线：分别检查 `Z>3`、`|Z|>3` 及染色体逐项规则对AB的复现效果 | 无 | 可调用的规则函数、`outputs/q4_rule_baseline.csv` |
| 3 | 建立主模型：以带正则化的Logistic回归为主，比较“仅Z值”“Z值+质量指标”“全特征”三层特征集；所有预处理封装进同一Pipeline | 二号先提供分组折索引即可 | `src/q4_model.py`、候选模型参数表 |
| 4 | 建立T13/T18/T21三个一对其余模型或逐染色体判定规则，处理多标签重叠 | 与主模型并行 | `predict_subtypes()`接口、逐类型样本外概率 |
| 5 | 向二号交付统一接口：输入事件表，输出异常概率、三类染色体概率及候选模型说明 | 任务2—4 | `fit_model()`、`predict_proba()`、`predict_subtypes()` |
| 6 | 根据二号的样本外评估结果冻结最终模型，并导出模型、系数和标准化参数 | 依赖二号首轮评估 | `outputs/q4_model.*`、`outputs/q4_coefficients.csv` |

### 一号实现要求

- 读段总数与唯一比对读段数、总体GC与分染色体GC高度相关时，优先用正则化、变量分组或删去冗余变量，不能逐变量筛选后直接把显著项拼在一起。
- Z值是AB判定的直接信息来源，规则基线必须保留；复杂模型只有在分组样本外结果确有改善时才采用。
- 样本量较小，不采用神经网络；树模型最多作为二号的非线性对照，不作为默认主模型。
- 模型输出必须是概率，最终0/1阈值由二号在训练折内选择。

### 时间线（一号）

- **T0–T1**：完成标签与特征审计、规则基线。
- **T1–T3**：完成三层Logistic候选与逐染色体模型，先交可调用接口。
- **T3–T5**：根据二号首轮样本外结果处理共线性、收敛和校准问题。
- **T5–T7**：冻结最终模型，导出模型参数及全部事件预测。

## 二、二号：分组验证、阈值选择与稳健性主线

### 任务清单

| # | 任务 | 依赖 | 交付物 |
|---|---|---|---|
| 1 | 搭建按孕妇分组的重复分层交叉验证；先用规则基线和占位Logistic跑通，避免等待一号 | 无 | 固定随机种子的折索引、`src/q4_evaluate.py` |
| 2 | 对比规则基线、仅Z值模型、全特征主模型和一个受限非线性模型；输出逐折与合并OOF指标 | 一号T3接口 | `outputs/q4_cv_metrics.csv`、`outputs/q4_oof_predictions.csv` |

| 5 | 稳健性分析：剔除QC异常事件、使用行级数据但仍按孕妇分组、去除/保留BMI、不同类别权重、阈值规则变化 | 一号接口可用后 | `src/q4_sensitivity.py`、`outputs/q4_sensitivity.csv` |

### 二号实现要求

- 使用 `StratifiedGroupKFold` 或等价的孕妇分组分层方案；若某个T13/T21验证折阳性太少，减少折数或采用重复分组留出，不得退回普通随机K折。
- 所有性能比较必须使用同一组OOF折；阈值不能直接在全数据上调到最好看。
- 主结果同时报告事件数和孕妇数。对同一孕妇标签变化的情况单独给出说明，不能把事件级准确率包装成孕妇级诊断准确率。
- AB是题面指定的判定结果，并非羊水穿刺或出生结局金标准；最终模型评价的是“复现AB判定”的能力，不得写成真实胎儿疾病诊断准确率。

### 时间线（二号）

- **T0–T1**：固定分组交叉验证折、指标与阈值规则，规则基线跑通。
- **T1–T3**：完成评估与绘图框架，用占位Logistic联调。
- **T3–T5**：接入一号模型，完成首轮模型比较、阈值和校准反馈。
- **T5–T7**：完成Bootstrap区间、敏感性和错误分析，给一号最终选择依据。

## 五、验收清单

- [ ] 标签仅来自AB，未使用AE或任何 `label*` 派生列作特征；
- [ ] 正式数据单位为554个抽血事件，同次技术重复未当独立样本；
- [ ] 所有划分均按147位孕妇分组，无孕妇跨训练/验证集；
- [ ] 预处理、特征选择和阈值选择均在训练折内完成；
- [ ] 未通过过采样或SMOTE改变天然类别比例；
- [ ] 同时报告PR-AUC、灵敏度、特异度、PPV、NPV、F1、ROC-AUC、Brier和混淆矩阵；
- [ ] 有规则基线，复杂模型的增益来自同折OOF比较；
- [ ] T13/T18/T21分别评估，并说明阳性样本量很小；
- [ ] 对QC、技术重复、特征集、类别权重和阈值做过稳健性分析；
- [ ] 固定随机种子后一条命令能重现所有CSV与图表；
- [ ] 结论明确限定为复现AB筛查结果，不冒充临床金标准诊断。

## 六、最容易翻车的四点

1. 普通随机切分605行，导致同一孕妇同时出现在训练集和验证集，性能虚高。
2. 把AB、其拆分标签或AE间接放入特征，形成标签泄漏或恒定标签。
3. 只报准确率/ROC-AUC，掩盖66/554的异常类不平衡与漏诊风险。
4. 直接追求复杂模型，却不与Z值规则做同折对照；若增益不稳定，应保留更简单、可解释的判定规则。
