# C 题 第二阶段分工：问题二（BMI 分组与最佳 NIPT 时点）

> **阶段目标**：给出 BMI 合理分组（连续区间、组间差异明显、组数适中）+ 每组最佳 NIPT 时点 + 检测误差影响分析。
>
> **分工原则**：**甲、乙做问题二里两件不同但互补的事，尽量互不阻塞；丙专注问题一的论文与画图。** 甲乙工作量大致相当，甲略重（多担一份文档主笔和一项后置分析）。

---

## 0. 开局 1 小时：三人一起对齐（甲乙必须当场谈拢一件事）

1. **风险函数 R(t) 的参数初稿**——这是甲乙两条线唯一的共享输入，必须当场拍板一版初稿（哪怕后面还会调），不能各自猜。建议分段：t≤12 低风险取基准值，13–27 线性上升，t≥28 取高值，再叠加"检测未达标需重测"的期望代价。**由甲主笔提案，乙当场提修改意见，10分钟内定稿一版可用的初稿**，后续允许调参但结构不再变。
2. 确认问题二的输入数据：`data/processed/male_clean_event.csv` 里的 `t_left/t_right/censored`（丙已备好的删失区间标记）+ `outputs/q1_coef.npy`（问题一模型，含 `predict_y/prob_qualified/week_reach` 接口，`bmi_baseline` 分组变量）。
3. 约定目录：

```
/code     q2_survival.py（甲）  q2_optimize.py（乙）  q2_sensitivity.py（乙）  q2_final.py（汇总）
/outputs  q2_*.txt / q2_*.npy / q2_*.csv
/figs     q2_fig*.png（丙画）
/docs     C题_第二阶段分工.md（本文件）  建模思路/问题二_建模思路.md（甲主笔，乙补充优化部分）
```

4. **关键设计**：乙不必等甲的生存分析建完才能开工——问题一已经导出了 `prob_qualified(week, bmi_baseline)` 接口，乙可以**立即**拿这个现成接口当"临时达标概率模型"，把优化算法框架搭起来、跑通。等甲的生存分析定稿后，乙只需要把接口换掉重新跑一遍，不需要从零开始。这就是"允许少量等待、但不能等一人完全做完"的具体做法。

## 一、甲：达标时间的统计建模主线（略重）

### 任务清单

| # | 任务 | 依赖 | 产出 |
|---|---|---|---|
| 1 | **风险函数 R(t) 主笔定稿**（含2-3组备选参数，供后续敏感性分析） | 与乙0小时对齐后独立完成 | `R(t)` 显式表达式 + 参数表 |
| 2 | **区间删失生存分析**：对每位孕妇的"首次达标孕周"用 Kaplan-Meier / AFT（Weibull 或对数正态）回归 T ~ BMI，产出比问题一参数化模型更严格的 T(BMI) 条件分布（含不确定性，不只是点估计） | 独立，用丙已备好的 `t_left/t_right/censored` | `predict_survival(bmi_baseline) -> T的分布`，接口签名与 Q1 的 `prob_qualified` 对齐，方便乙直接替换 |
| 3 | **检测误差向下游传播**：把问题一已量化的测序误差方差（`s2_tech`）和模型参数不确定性，通过 Monte Carlo 或 Delta 方法传播到 T(BMI) 分布和风险估计上——这是题面"分析检测误差对结果的影响"的核心 | 依赖①②完成 | 误差传播后的风险区间/达标时间置信带 |
| 4 | **组数 k 的判据分析**：为什么分成这么多组而不是更多或更少，要有信息准则或风险曲线拐点支撑 | **依赖乙产出的"不同k下最优风险"曲线**（乙②），是本阶段唯一需要等乙的地方 | k 的选择依据（一段论证+一张曲线） |
| 5 | 主笔《建模思路/问题二_建模思路.md》（题目拆解、决策点、最终模型、检验、局限、图表需求） | 贯穿全程，最后收尾 | 完整文档（乙负责补充"优化算法"一节） |

### 时间线（甲）

- **T0–T1**：与乙对齐 R(t) 初稿。
- **T1–T5**：任务①②并行推进（① 半天内可定稿；②预计耗时最长，先出 Kaplan-Meier 描述性结果，AFT回归定稿可以稍晚）。**T3左右先把②的接口签名和一个粗糙可用版本给乙**，让乙能提前试接，不用等到完全定稿。
- **T5–T8**：任务③误差传播。
- **T8起**：等乙的"风险vs组数"曲线出来后，做任务④（k的判据），同时开始动笔文档。
- **T10–T12**：文档定稿、和乙的敏感性分析结果对齐、交给丙一份"问题二结果速览"供画图。

## 六、这一阶段最容易翻车的三点

1. **甲乙的 R(t) 没在 T1 真正对齐**，各自按自己理解的参数往下做，到 T8 合并时发现两条线基于不同的风险定义，前面工作全部要返工——T0-T1 这一步态度要认真，别走过场。
2. **乙直接上聚类分组**——评阅要点明确写了"直接聚类不是一个好的分组方法"，必须是动态规划最优分割或等价的、以风险函数为目标的组合优化。
3. **甲的生存分析和 Q1 的参数化模型如果结论不一致，被简单地"择一隐藏另一个"**——两条路径的差异本身是有信息量的（发现的话要讨论原因，可能是删失机制、参数化假设的差异），不能因为对不上就悄悄扔掉一条，那是本阶段乙任务④存在的意义。
