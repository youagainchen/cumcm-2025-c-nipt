# 问题三：一号多因素达标时间模型

## 1. 任务定位

问题三在问题二的 BMI 分组基础上，进一步考察身高、体重和年龄是否会改变 Y 染色体浓度达到 4% 的时间分布。分组仍然只能使用首次检测 BMI，因为制定初检计划时未来的检测结果和 BMI 不可知；身高、体重和年龄作为个体风险修正变量交给二号的优化器使用。

## 2. 数据口径

男胎数据共有 267 位孕妇和 1021 个抽血事件。一次抽血的技术重复先取事件内 Y 浓度均值，同一孕妇不同抽血保留为纵向重复观测。达标事件定义为事件均值不低于 0.04。首次达标时间使用 `t_left`、`t_right` 和 `censored` 表示区间删失：首测已达标为左删失，观察到未达标到达标的转变为区间删失，全程未达标为右删失。

## 3. 两条建模路径

### 3.1 多因素混合效应模型

响应变量取平方根尺度，以减轻 Y 浓度的偏态和异方差：

$$
\sqrt{Y_{ij}}=f(week_{ij})+x_i^T\beta+u_i+\varepsilon_{ij}.
$$

其中 (f) 为孕周 B-spline，(u_i) 为孕妇随机截距，(x_i) 为标准化的基线协变量。比较 BMI+年龄、身高+体重+年龄、BMI 对身高体重的残差+年龄和全变量四种设定，用 ML 的 AIC/BIC 选择。

本次运行中，混合模型的 AIC 最优设定为身高+体重+年龄。该结果用于检验多因素对单次检测浓度的影响，并可通过正态近似转换成单次检测达标概率。

### 3.2 区间删失 AFT 模型

令 (T) 为首次达到 4% 的潜在孕周，使用：

$$
\log T=\beta_0+\beta_1x_1+\cdots+\beta_px_p+\sigma\epsilon.
$$

对左删失、区间删失和右删失直接写入区间删失似然。比较 Weibull、LogNormal 和 LogLogistic 分布，并以 AIC 选择主分布。本次运行中 AIC 最优为 BMI+年龄的 LogNormal AFT 模型，BMI 系数为正表示 BMI 越高，达到 4% 的时间越晚。

## 4. 给二号的接口

模型文件 `outputs/q3_model.npy` 保存分布、协变量中心化常数、参数估计和协方差矩阵。调用方式：

```python
from code.q3_model import load_prob_fn

prob_qualified = load_prob_fn()
p = prob_qualified(14, 35, 165, 80, 32)
p_retest = prob_qualified(17.7, 35, 165, 80, 32, prev_week=14)
```

无 `prev_week` 时返回累计首次达标概率 (P(T\leq t))；有 `prev_week` 时返回：

$$
P(prev<T\leq t\mid T>prev)
=\frac{F(t)-F(prev)}{1-F(prev)}.
$$

二号在复检递归中必须使用后一个条件概率，不能每轮重复使用累计概率。

## 5. 当前输出

- `outputs/q3_aft_candidates.csv`：12 个 AFT 候选模型的 log-likelihood、AIC 和收敛状态；
- `outputs/q3_mixed_candidates.csv`：4 个纵向混合模型的比较；
- `outputs/q3_mixed_fixed_effects.csv`：混合模型固定效应；
- `outputs/q3_model.npy`：二号调用的 AFT 概率接口参数；
- `outputs/q3_uncertainty_summary.csv`：参数联合抽样后的 BMI=30、35、40 达标时间区间；
- `outputs/q3_measurement_sensitivity.csv`：去除、保留和加倍技术误差的概率对照；
- `outputs/q3_model_summary.txt`：运行元数据和候选模型摘要。

## 6. 结果解释边界

当前数据中 81% 左右的孕妇首测即达标，真实达标时间存在较强左删失，因此不能把首次观测到达标的孕周直接当作真实事件时间。AFT 结果适合提供稳健性路径和个体条件概率，不能替代对单次检测判定口径更直接的纵向混合模型。身高、体重和 BMI 存在结构性相关，论文中应报告候选设定和共线性处理，不能把所有系数作简单因果解释。

## 7. 复现

```powershell
python code\q3_model.py --bootstrap 500
```

正式论文使用默认完整抽样次数；开发调试可暂时使用较小的 `--bootstrap`，但不能把调试次数写成最终不确定性结论。
