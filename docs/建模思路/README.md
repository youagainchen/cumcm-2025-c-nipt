# 建模思路文档夹

这个文件夹**不是论文**，是论文的上游。每一问都要在这里留一份 `问题X_建模思路.md`，服务两类读者：

1. **写论文的人（丙）** —— 直接从这里抄结构、抄公式、抄数字、抄结论句，并按「图表需求」一节作图，不用回去读代码；
2. **检查建模逻辑的人** —— 顺着「决策点」一节逐条复核，看每个选择有没有证据支撑。

## 每份文档必须包含的十节（顺序固定，方便交叉对照）

| # | 小节 | 作用 |
|---|---|---|
| 1 | **题目要求拆解** | 把题面那句话拆成几个可交付项，防止漏答 |
| 2 | **数据事实** | 这一问用到的数据规模、结构、坑，全部列清 |
| 3 | **建模路线图** | 从原始数据到最终结论中间经过哪几步 |
| 4 | **决策点** | ⭐核心。每个岔路口：选了什么、备选是什么、依据的证据（数字）、选错会怎样 |
| 5 | **最终模型** | 显式表达式 + 符号说明 + 参数估计表 |
| 6 | **结果与解读** | 数字 + 一句话人话解释，供摘要直接引用 |
| 7 | **检验与诊断** | 显著性、拟合优度、诊断、稳健性 |
| 8 | **图表需求** | ⭐建模的人**只描述要什么图**，画图由丙统一完成 |
| 9 | **局限与反驳预案** | 评委可能怎么质疑，我们的回应是什么 |
| 10 | **对下一问的接口** | 这一问产出什么给后面用，怎么调用 |

## 分工边界

- **建模的人（甲/乙）**：负责第 1~7、9、10 节，以及第 8 节的**图表需求描述**（画什么、横纵轴是什么、要体现什么结论）。
- **写论文的人（丙）**：负责按第 8 节的描述**实际作图**，统一走 `src/plot_style.py`，输出到 `figures/`，300 dpi PNG。

## 写作纪律

- **每个结论后面必须跟数字**。「BMI 影响显著」不算，「BMI 每增 1 单位 Y 浓度降 0.113 个百分点，p=0.036」才算。
- **决策点一节要写"为什么不选另一个"**。论文正文里未必写，但这里必须留档，评委问起时才答得上来。
- **数字全部从脚本输出复制，不许手抄**。脚本改了，文档同步改，并在文末更新「最后同步时间」。
- 图表需求要写到丙**不看代码也能画出来**的程度：图号、类型、横纵轴、分组、要标注什么、想说明什么结论。
